# Operation: BUILD

My 90-day journey from learning to building software.

## Goal

Become capable of taking real problems and turning them into functional software.

## Progress

### Day 1 — Foundation

Set up my development environment, Git, and GitHub. Started Operation: BUILD and created my first HTML baseline.

### Day 2 — Git & HTML

Practiced the Git workflow and continued building with HTML. Learned how Git tracks project changes and updated my HTML baseline.

### Day 3 — Responsive Page

Built my first responsive web page and began applying responsive layout principles with HTML and CSS.

### Day 4 — UI Builds

Focused on recreating and building user interfaces with HTML and CSS, improving my understanding of structure, spacing, and visual layout.

### Day 5 — Flexbox

Built a responsive project using CSS Flexbox and strengthened my understanding of flexible layouts and responsive positioning.

### Day 6 — Grid Dashboard

Built a dashboard layout using CSS Grid. Practiced creating structured multi-column layouts and controlling how elements occupy space within a grid.

### Day 7 — Responsive Design

Focused on responsive design and adapting layouts for different screen sizes. Practiced using responsive CSS techniques to make interfaces work across devices.

### Day 8 — Forms & Accessibility

Learned and practiced building forms while introducing accessibility considerations into the interface.

### Day 9 — JavaScript Foundation

Started working with JavaScript fundamentals and learned how JavaScript can add behavior and interactivity to web pages.

### Day 10 — Task Tracker

Built a functional task tracker using JavaScript and the DOM. Practiced selecting elements, responding to user interactions, and dynamically updating the interface.

## What I'm Building

This repository documents my progression from learning the fundamentals of software development to building functional software independently.

Each day is focused on learning a concept, applying it through code, and committing the result.

## 90-Day Mission

**Learn → Build → Solve → Ship**

The objective is not simply to complete tutorials.

The objective is to become a builder who can take a real problem, break it down, design a solution, write the code, and turn the idea into working software.
